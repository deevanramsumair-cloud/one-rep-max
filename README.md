# 1RM Calculator

A simple gym tool that estimates your one-rep max (1RM) using the Epley formula.

## Features
- Calculates estimated 1RM from weight and reps
- Supports kg and lbs
- Instant results
- Mobile friendly

## Formula
1RM = weight × (1 + reps / 30)
